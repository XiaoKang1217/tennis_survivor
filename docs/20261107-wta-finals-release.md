# WTA 年终上线

## 执行文件

在 Supabase SQL Editor 中完整执行 `20261107-wta-finals-release.sql`。文件本身是纯 SQL，没有 Markdown 围栏；四部分合并在一个事务中，失败会回滚，可重复执行。代码发布不等待 SQL，但费用、结算和开售弹窗的后端功能需要 SQL 执行成功后才能使用。

## 本站规则

- 北京时间 2026-11-09 04:00 截止提交，开售弹窗同时停止。
- 1–2 人；普通账号每人 1000 本金，固定八个账号免费。资格按用户 UUID 验证并写入合同。
- 不发签约金、开户本金、额外本金或提交奖励。现有钱包余额原样保留。
- 不参与 Combo、低保办。ATP/WTA 年终均禁止换人，后端也会拒绝换人请求。
- 小组赛逐胜累计，按签表明确出现的 SF/F/W 晋级阶段追加奖励。小组赛一次胜负不直接判断晋级或淘汰。
- 普通账号：RR 每胜 200，SF +1000，F +2000，W +4000。
- 固定前八：RR 每胜 250，SF +1500，F +3000，W +6000。
- 每次更新只结算累计应得与已支付之差。源数据回退导致应得减少时停止并报错，不自动扣用户本金。
- 两场同一官方赛程日的 WTA 竞猜；比赛不足则留空，后续补齐，不替换已发布场次。
- 本站/上站榜单和收益仍分别为年终、巴黎＋香港。旧站单败淘汰结算函数保留，只增加年终分支。

- 50 项年终及竞猜专项测试、45 项旧站结算/锁价/流水等回归测试通过。
- 隔离 PostgreSQL 执行迁移、提交、撤回、重提、分次结算、重复结算和权限测试。
- 核验普通账号伪造免费价格无效，前八免费；新账户余额 0、现有余额不增加，提交奖励流水不存在。
- 核验同一 WTA 赛事可发布两场且每场身份保持不变。
- 2025 源签表实际解析：雷巴金娜 3 胜冠军，萨巴莲卡 3 胜决赛，佩古拉和阿尼西莫娃各 2 胜半决赛。替补与退赛球员身份分开。
- 桌面与 390px 手机端测试选人、计算器、模拟提交/撤回，收益表无页面横向溢出。
- 二维码 WebP 约 59 KiB，共用同一文件。实际加载速度取决于网络，不承诺所有网络均一秒内。

## 结算核算

“一人小组赛2胜夺冠＋一人3胜进SF”：普通毛收益 `(400+1000+2000+4000)+(600+1000)=9000`；前八毛收益 `(500+1500+3000+6000)+(750+1500)=13250`。

最高毛收益：普通 `7600+3600=11200`，前八 `11250+5250=16500`。普通双人签约净收益最高为 9200。前八资格冻结，后续榜单排名变化不改变费用及收益。
