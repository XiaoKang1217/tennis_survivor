# 巡回赛经纪人每日结算设计

## 目标

巡回赛经纪人不是只等整站结束才刷新。正式版每天结算昨天已经完赛的结果，让用户在「我的阵容」「配置大厅」「榜单」里看到自己的阵容正在赚钱或亏钱。

## 结算输入

- `manager_tournaments`: 赛季、巡回赛、赛事 ID、赛事名称、级别、场地、签数、开始/结束日期、数据源。
- `manager_lineups`: 用户、赛站、锁定状态、提交时间、阵容成本、本站签约金占用、钱包占用。
- `manager_contracts`: 每个用户签下的球员合同，含球员、身价、签约时间、是否换人合同、已确认到达轮次。
- `manager_results_daily`: 每天抓取的赛果快照，含球员、赛站、比赛日期、已到达轮次、是否出局。
- `manager_wallet_transactions`: 钱包流水，含提交奖励、低保、球员收益补差、手续费、最终结算。

## 每日结算流程

1. 定时任务每天读取昨天完赛的赛果。
2. 按赛站和球员匹配所有未结束合同。
3. 计算球员新到达轮次对应的积分收益。
4. 若新轮次收益高于合同已入账收益，只发放差额。
5. 若球员已出局，合同标记为最终轮次。
6. 同步更新用户阵容当前收益、配置大厅展示值和公共榜单快照。
7. 整站结束后追加 Combo，并写入最终净收益。

## 幂等规则

- 每条结算流水使用 `contract_id + round + settled_date` 作为唯一键。
- 同一球员同一轮次重复抓取时不重复发放。
- 若赛果数据更正，只允许管理员任务生成反向修正流水，保留账本可追溯性。

## 前端同步

- 「我的阵容」显示每个合同的已入账轮次、当前收益、最终状态。
- 「配置大厅」展示已锁定阵容的当前结算进度，未锁定前可匿名或延迟展示。
- 「榜单」按每日结算快照刷新本站收益榜、赛季经理榜、王牌球员和调仓大师榜。

## 换人处理

- 换下合同不删除，只标记为 `replaced`，保留沉没成本和已入账收益。
- 换上合同从确认时间之后的未开赛场次开始计算。
- 手续费单独写入钱包流水，方便资金账本解释每一笔变化。
